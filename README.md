# 🏴‍☠️ Sail of Destiny

An epic pirate adventure endless runner game built for Telegram Mini Apps. Navigate the treacherous seas, collect treasures, avoid dangers, and become the legendary captain of the ocean!

## 🌊 Game Features

### ⚔️ Core Gameplay
- **Endless Sailing**: Navigate your ship across the vast pixel ocean
- **Touch/Keyboard Controls**: Intuitive steering with responsive controls
- **Progressive Difficulty**: Game speed increases as you sail further
- **Distance Scoring**: Track how far you can sail before disaster strikes

### 🌦️ Dynamic Weather System
- **Clear Skies**: Normal sailing conditions
- **Rain Storms**: Reduced visibility and challenging conditions
- **Fog**: Limited visibility adds to the challenge
- **Thunder Storms**: Lightning strikes with dramatic effects

### ⚓ Obstacles & Dangers
- **🧊 Icebergs**: Frozen obstacles that damage your hull
- **🌀 Whirlpools**: Swirling vortexes that pull your ship
- **🪵 Drifting Logs**: Wooden debris to avoid
- **💣 Sea Mines**: Explosive hazards in the water

### 💰 Treasures & Power-ups
- **🪙 Coins**: Basic treasure for scoring
- **📦 Treasure Chests**: High-value rewards
- **💎 Gems**: Precious gems worth extra points
- **💨 Speed Boost**: Temporary speed enhancement
- **🛡️ Shield**: Protection from damage
- **⏰ Slow Time**: Slows down obstacles

### 👨‍✈️ Captain Personalization
- **Telegram Avatar Integration**: Your photo becomes your captain portrait
- **Captain Flag**: Your avatar on the ship's sail
- **Multiple Ship Options**: Unlock different ships with unique abilities

### 🏆 Progression System
- **Local Leaderboard**: Compete against your own best scores
- **Ship Unlocks**: Purchase new ships with collected treasures
- **Achievement System**: Track your sailing accomplishments
- **Persistent Save**: Your progress is automatically saved

### 🎵 Epic Sound Experience
- **Ocean Ambiance**: Realistic wave sounds
- **Storm Audio**: Dynamic weather sound effects
- **Power-up Sounds**: Audio feedback for all actions
- **Epic Music**: Pirate adventure soundtrack

## 🎮 How to Play

### Controls
- **Mouse/Touch**: Click or tap to steer left/right
- **Keyboard**: Arrow keys or A/D to steer
- **Spacebar**: Pause/Resume game

### Objective
1. **Avoid Obstacles**: Don't let your hull reach 0%
2. **Collect Treasures**: Gather coins, chests, and gems
3. **Grab Power-ups**: Use temporary advantages wisely
4. **Survive Weather**: Adapt to changing conditions
5. **Sail Far**: Beat your distance records

### Tips
- **Collect treasures early** to unlock better ships
- **Use shields strategically** during tough sections
- **Watch the weather** and adjust your sailing style
- **Master the controls** for precise navigation

## 🚀 Getting Started

### Local Development
```bash
# Clone or download the project
cd sail-of-destiny

# Install dependencies
npm install

# Start the development server
npm start
```

### Telegram Mini App Setup
1. Create a bot with [@BotFather](https://t.me/BotFather)
2. Set your game URL in BotFather
3. Configure commands and descriptions
4. Test on Telegram
